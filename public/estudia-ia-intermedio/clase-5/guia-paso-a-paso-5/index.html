6Camino B: de un mensaje a una lista de números

20 min

Qué haces. Conviertes cada mensaje en un vector de 384 números con un modelo que queda congelado.

6.1 Qué es una representación

Un encoder convierte una frase en una lista de números (un vector). Frases con el mismo significado quedan con vectores parecidos aunque usen otras palabras. Si no actualizamos ningún parámetro del encoder, decimos que está congelado.

6.2 El modelo, con su ficha

PreguntaRespuesta
Nombresentence-transformers/paraphrase-multilingual-MiniLM-L12-v2
¿Qué es?Un encoder de la familia BERT con 12 capas y unos 118 millones de parámetros. Devuelve 384 números por frase.
¿Idioma?50 idiomas, entre ellos español.
¿Para qué se entrenó?Para que frases con el mismo significado queden cerca entre sí (similitud de oraciones).
¿Qué NO tiene?Ninguna salida de clases: no sabe qué es «facturación» ni «envío».
Licencia y tamañoApache 2.0, unos 470 MB. Lee hasta 128 tokens.

Es distinto al modelo de la clase 4: aquel decide si una hipótesis se sigue del mensaje; este solo produce vectores.

6.3 Cargarlo y congelarlo

Celda de códigoMODELO_EMB = "sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2" tok_emb = AutoTokenizer.from_pretrained(MODELO_EMB) enc = AutoModel.from_pretrained(MODELO_EMB) enc.eval() for p in enc.parameters(): p.requires_grad = False # congelado: ningún parámetro del modelo se va a actualizar total = sum(p.numel() for p in enc.parameters()) entrenables = sum(p.numel() for p in enc.parameters() if p.requires_grad) print(f"Parámetros del modelo: {total / 1e6:.0f} millones | entrenables ahora: {entrenables}")
Así sabes que quedó bienDice «Parámetros del modelo: 118 millones | entrenables ahora: 0». La primera vez descarga el modelo; sigue leyendo mientras carga.

6.4 De texto a vector

El modelo da un vector por cada token. Se promedian los de la frase (ignorando el relleno) y queda uno por mensaje, que es lo que recomienda la ficha del modelo.

Celda de códigodef incrustar(textos, lote=32): """Devuelve una matriz (mensajes x 384) con el vector de cada mensaje.""" salidas = [] for i in range(0, len(textos), lote): ent_ = tok_emb(textos[i:i + lote], padding=True, truncation=True, max_length=128, return_tensors="pt") with torch.no_grad(): h = enc(**ent_).last_hidden_state # (frases, tokens, 384) m = ent_["attention_mask"].unsqueeze(-1).float() # 1 en tokens reales, 0 en relleno salidas.append(((h * m).sum(1) / m.sum(1)).numpy()) # promedio sobre los tokens reales return np.vstack(salidas) t0 = time.time() X = incrustar(df["mensaje"].tolist()) print(f"Matriz de representaciones: {X.shape} en {time.time() - t0:.0f} s") print("Primeros 5 números del primer mensaje:", np.round(X[0, :5], 3))

6.5 ¿Se parecen los vectores de frases con el mismo significado?

La similitud coseno vale 1 si dos vectores apuntan en la misma dirección. Escribe antes cuáles esperas que sean mayores.

Celda de códigodef coseno(a, b): return float(a @ b / (np.linalg.norm(a) * np.linalg.norm(b))) par = incrustar(["me cobraron dos veces el pedido", "me hicieron un cargo doble por la compra", "mi paquete no ha llegado todavía"]) print("cobro doble vs cargo doble :", round(coseno(par[0], par[1]), 2), "(mismo significado, otras palabras)") print("cobro doble vs paquete :", round(coseno(par[0], par[2]), 2), "(otro tema)")
Cómo se leeSi «cobro doble» y «cargo doble» salen con una similitud claramente mayor que «cobro doble» y «paquete», el vector está recogiendo el significado, no solo las palabras.

Qué haces. Entrenas una capa pequeña encima de los vectores y la mides en validación.

7.1 Entrenar con los 208 mensajes

Una regresión logística multiplica el vector de 384 números por una matriz de pesos y da una probabilidad por clase: 384 × 3 + 3 = 1.155 números por aprender, contra 118 millones que no se tocan.

7.2 ¿Cuántos datos hacen falta y cuánto es azar?

Entrenamos cinco veces con el 25 %, el 50 % y el 100 % del entrenamiento. Mira el rango (mínimo y máximo) de cada fila: eso es lo que no puedes distinguir de una mejora real.

Celda de códigorng = np.random.RandomState(SEMILLA) idx_ent = np.where(m_ent)[0] filas = [] for frac in [0.25, 0.5, 1.0]: ks = [] for rep in range(5): n = int(frac * len(idx_ent)) sel = idx_ent if frac == 1.0 else rng.choice(idx_ent, size=n, replace=False) mod_ = LogisticRegression(max_iter=2000).fit(X[sel], y[sel]) ks.append(int((mod_.predict(X[m_val]) == y[m_val]).sum())) filas.append({"datos de entrenamiento": f"{int(frac * 100)} % ({int(frac * len(idx_ent))} mensajes)", "aciertos (mín - máx)": f"{min(ks)} - {max(ks)} de {int(m_val.sum())}"}) pd.DataFrame(filas)

7.3 Un único cambio más: la regularización C

Un valor bajo de C hace que la salida se aferre menos a los datos de entrenamiento. Todo lo demás queda igual que en B1.

Celda de códigofor C_ in [0.1, 10.0]: mod_ = LogisticRegression(max_iter=2000, C=C_).fit(X[m_ent], y[m_ent]) p = mod_.predict(X[m_val]) registrar(f"B2 salida logística con C={C_}", f"solo cambia C (de 1 a {C_})", va["etiqueta"], p) pd.DataFrame(LOG)
Cómo se leeSi con la mitad de los datos se obtiene casi lo mismo, conseguir más etiquetas no es lo urgente. Si los rangos de dos opciones se solapan, la diferencia no sostiene una decisión.
Una salida entrenada también puede engañarteCon pocos datos aprende atajos, y si un mensaje de validación tiene gemelo en entrenamiento, el acierto sale inflado. Por eso la partición va por grupo.

8Camino C: se diseña, no se entrena

10 min

Qué haces. Calculas cuánto costaría afinar parte del modelo, sin entrenar nada.

Celda de códigodef parametros(*prefijos): return sum(p.numel() for n, p in enc.named_parameters() if any(n.startswith(x) for x in prefijos)) salida_p = 384 * 3 + 3 ultimas2 = parametros("encoder.layer.10.", "encoder.layer.11.") filas = [] for nombre, entrenables_ in [("B · solo la salida", salida_p), ("C1 · últimas 2 capas + salida", ultimas2 + salida_p), ("C2 · todo el modelo + salida", total + salida_p)]: # Estimación en float32: pesos (4 B) + por cada parámetro entrenable, gradiente (4 B) y dos estados de Adam (8 B) mb = (total * 4 + entrenables_ * 12) / 1e6 filas.append({"camino": nombre, "parámetros que se actualizan": f"{entrenables_:,}".replace(",", "."), "% del modelo": f"{100 * entrenables_ / total:.2f} %", "memoria aprox. (MB)": round(mb)}) pd.DataFrame(filas)
Cómo se leeLa memoria es una estimación en float32 con el optimizador Adam, sin contar activaciones. Sirve para ver el orden de magnitud: afinar pasa de miles de números a millones.

Qué haría falta para justificar C:

  • Un tipo de error concreto que esperas arreglar, con ejemplos (no «mejorar en general»).
  • Suficientes ejemplos por clase y sin casi-duplicados entre conjuntos.
  • Un punto de partida guardado para volver atrás, y una prueba que no hayas mirado.
Regla de honestidadSi no entrenaste algo, no lo cuentes como hecho. En tu ficha, el camino C queda como diseño, no como resultado.

9Compara y mira qué errores cambian

Glosario y lista final

Transferencia: usar lo que un modelo ya aprendió para una tarea nueva.

Representación (vector, embedding): lista de números que resume el significado de un texto.

Congelar: dejar sin actualizar los parámetros de un modelo.

Regresión logística: una capa que convierte un vector en una probabilidad por clase.

Parámetro: un número del modelo que se ajusta al entrenar.

Afinar (fine-tuning): entrenar también algunas capas del modelo grande.

Regularización (C): qué tanto se aferra la salida a los datos de entrenamiento.

Similitud coseno: qué tan parecidos son dos vectores (1 = misma dirección).

Sobreajuste: aprender atajos del entrenamiento que no sirven con mensajes nuevos.

Hipótesis: qué cambio haces, qué esperas que pase y por qué, escrito antes de ejecutar.
