A · Desde la base

¿Qué es un dato para una máquina?

Todo entra como números

Una red neuronal no ve fotos ni lee palabras: recibe números y devuelve números.

  • Una imagen en escala de grises es una tabla de brillos: 0 = negro, 255 = blanco. En color son 3 tablas (rojo, verde, azul).
  • Un texto puede convertirse en un vector: una posición por palabra del vocabulario, con 1 si aparece («bolsa de palabras»).
  • Una etiqueta («envío», «gato») también se vuelve un número: 0, 1, 2…

Lo que la red «sabe» depende de cómo preparamos esos números.

A · Desde la base

¿Qué es un modelo?

Software tradicional

Una persona escribe las reglas

Reglas + datos → respuestas.
IVA en Excel: $100.000 → $19.000, siempre.

Modelo de machine learning

El sistema aprende las reglas

Datos + respuestas → reglas (el modelo).
Spam: aprendió de millones de correos marcados.

Un modelo es una función que recibe una entrada y produce una salida. Sus parámetros, los números internos, no los escribe nadie: se ajustan con ejemplos.

A · Desde la base

Cómo aprende una máquina: datos, entrenamiento, uso

1DatosMuchos ejemplos del problema con su respuesta: fotos de prendas con su nombre, mensajes con su área.
2EntrenamientoEl modelo ajusta sus parámetros para equivocarse menos en esos ejemplos. El resultado es un modelo entrenado.
3Uso (inferencia)El modelo entrenado responde casos nuevos. Aquí ya no aprende: aplica lo aprendido.

Entrenar es caro y se hace pocas veces; usar es barato. Por eso reutilizar modelos ya entrenados es tan útil.

A · Desde la base

La neurona artificial

Peso grande = esa entrada importa mucho. Peso negativo = esa entrada resta (ir en carro baja las ganas de llevar paraguas). Sesgo = la tendencia sin información.

¿Llevo paraguas?

0,8·2 + 0,7·3 + 0·(−4) − 2 = 1,7
sigmoide(1,7) = 0,85 → sí

Una neurona multiplica cada entrada por un peso, suma y agrega un sesgo, y pasa el resultado por una activación.

Aprender = encontrar buenos pesos y sesgos con ejemplos.

A · Desde la base

Funciones de activación

ActivaciónQué haceDónde se usaEjemplo
ReLUSi el valor es negativo devuelve 0; si es positivo lo deja igual.Capas ocultas (la más común)ReLU(−3) = 0 · ReLU(2,5) = 2,5
SigmoideAplasta cualquier número entre 0 y 1.Salida sí/no (binaria)sigmoide(0) = 0,5
SoftmaxConvierte una lista de números en probabilidades que suman 1.Salida con varias clases[2, 1, 0] → [0,67; 0,24; 0,09]

¿Por qué existen? Sin activación, apilar 10 capas sería igual a tener una sola: todo sería una suma ponderada.
Ojo con softmax: un 95 % es la confianza del modelo, no una garantía de acierto.

A · Desde la base

La red neuronal: capas de neuronas

  • Entrada: recibe los números (784 píxeles).
  • Ocultas: transforman la información; cada capa combina lo que produjo la anterior.
  • Salida: una neurona por clase (10 prendas), con softmax.
  • Densa (Dense): cada neurona se conecta con todas las entradas.

Parámetros de una capa densa = entradas × neuronas + neuronas

A · Desde la base

¿De dónde salen los 101.770 parámetros?

784Entradas: una imagen de 28 × 28 píxeles.
100.480Primera capa oculta: (784 × 128) + 128.
1.290Capa de salida: (128 × 10) + 10.
101.770Total: números ajustables (pesos y sesgos).
Camiseta 67 %Pantalón 24 %Zapato 9 %… suman 100 %

Esos valores no son reglas que programamos: son números que la red ajusta al entrenar.

A · Desde la base

Bajar la montaña: la tasa de aprendizaje

La analogía

Entrenar es bajar una montaña con niebla: no vemos el valle, pero sentimos la inclinación bajo los pies.

El tamaño del paso importa

  • Paso pequeño (tasa 0,05): llega, pero muy despacio.
  • Paso adecuado (tasa 0,3): llega rápido al mínimo.
  • Paso enorme (tasa 1,05): se pasa del valle y se aleja; en una red se ve como loss: nan.

La pérdida es la altura; el gradiente, la inclinación; la tasa de aprendizaje (learning rate), el largo de la zancada.

A · Deep learning para visión

¿Por qué una CNN?

Red densa

Cada píxel con cada neurona

784 → 128 → 10 = 101.770 parámetros

Red convolucional (CNN)

Filtros que recorren la imagen

Conv → Pool → Conv → Pool → Dense = 12.810 parámetros

Como el mismo filtro se usa en toda la imagen, la CNN tiene unas 8 veces menos parámetros y logra una exactitud muy parecida (en clase: 83,6 % frente a 83,9 % de la densa).

A · Deep learning para visión

Cómo trabaja una CNN

Filtro 3×3

Busca un patrón: un borde, una textura.

Pooling

Resume la información y reduce el tamaño.

Capas

Bordes → formas → partes → «camisa».

Primero extrae patrones; al final, una capa densa decide.

C · Solución

¿Por qué se confunde con estos mensajes?

Representación

Palabras sin orden

«No quiero devolver…»: la bolsa de palabras ve «devolver» y pierde la negación.

Decisión del modelo

Mensajes ambiguos

Facturación y envío se mezclan: «La factura llegó pero el producto no».

Preparación

Vocabulario limitado

Con 30 mensajes, «chunche» puede ser una palabra desconocida.

Clave · No basta con reconocer palabras: debemos comprobar la intención.

Referencia de la presentación: 3 de 6 aciertos. En Colab pueden variar las predicciones.
