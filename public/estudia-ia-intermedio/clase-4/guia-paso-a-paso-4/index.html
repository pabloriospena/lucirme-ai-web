ConjuntoPara qué sirveCuándo se mira

El riesgo: si un cliente insistió tres veces y un mensaje queda en entrenamiento y otro en validación, el modelo vería casi el mismo texto en ambos lados y la medida saldría inflada. Por eso se reparte por grupo.

4.3 Cómo clasifica en tus clases si no fue entrenado con ellas

Con la técnica zero-shot: por cada etiqueta que le das arma una hipótesis («Este ejemplo es envío.») y le pregunta al modelo si esa hipótesis se sigue del mensaje. Gana la etiqueta con más probabilidad de entailment. El modelo interpreta tus clases por el significado de las palabras.

  • Siempre la clase más grande: no usa el texto.
  • Palabras clave: reglas escritas a mano. No es una red neuronal y a veces es difícil de superar.

Una función (def) recibe datos, hace algo con ellos y devuelve un resultado. Aquí se definen dos, por_palabras y resumen, y se reutilizan.

Celda de códigoCLASE_MAYOR = df.loc[df["conjunto"] == "entrenamiento", "etiqueta"].mode()[0] PALABRAS = { "facturación": ["factur", "cobr", "iva", "nit", "pago", "pagu", "nota crédito", "nota credito", "valor", "cargo", "cuota", "descuento", "cupón", "cupon", "extracto"], "envío": ["guía", "guia", "llega", "llegó", "llego", "entrega", "dirección", "direccion", "mensajero", "paquete", "despacho", "seguimiento", "transportadora", "domicilio", "pedido"], "devolución": ["devol", "reembols", "cambio", "garantía", "garantia", "defectuos", "dañado", "danado", "talla", "retracto", "no me sirve", "no lo quiero"], } def por_palabras(mensaje): """Cuenta cuántas palabras clave de cada clase aparecen y elige la que más.""" m = mensaje.lower() puntos = {c: sum(p in m for p in lista) for c, lista in PALABRAS.items()} mejor = max(puntos.values()) if mejor == 0: return CLASE_MAYOR return [c for c in CLASES if puntos[c] == mejor][0] def resumen(reales, predichas, nombre): """Devuelve una fila con aciertos, exactitud y F1 macro.""" aciertos = int((np.array(reales) == np.array(predichas)).sum()) return {"método": nombre, "aciertos": f"{aciertos} de {len(reales)}", "exactitud": round(accuracy_score(reales, predichas), 2), "F1 macro": round(f1_score(reales, predichas, labels=CLASES, average="macro", zero_division=0), 2)} df["pred_mayoritaria"] = CLASE_MAYOR df["pred_palabras"] = df["mensaje"].apply(por_palabras) print("Clase más grande en entrenamiento:", CLASE_MAYOR)

Ahora el modelo, sobre los 344 mensajes. Cada predicción se guarda con su confianza y con las tres probabilidades, para poder rastrear después cualquier error.

Qué haces. Le pides a Claude, ChatGPT o Gemini que clasifique los mismos 30 mensajes y mides su respuesta con las mismas métricas.

Qué es lo que cambia. Un chat es un modelo generativo: predice el siguiente token a partir de todo lo anterior, así que escribe la etiqueta como texto. No se cambia ningún parámetro del modelo al preguntarle. A veces el mismo mensaje recibe otra respuesta porque el modelo muestrea entre opciones probables. Por eso su salida también se valida, igual que la del modelo anterior.

10Cómo empezar con tu propio caso en Hugging Face

20 min

Qué haces. Aplicas lo mismo a la tarea de tu proyecto.

  1. Define tu tarea y tus etiquetas en una frase: «clasificar [qué] en [etiquetas]».
  2. Busca un modelo. En huggingface.co/models filtra por Tarea (por ejemplo Text Classification, Zero-Shot Classification o Image Classification) y por Idioma. Ordena por «Más descargados» o «Tendencias».
  3. Lee la ficha: idioma, tarea, etiquetas de salida, datos de entrenamiento y su tamaño, licencia, tamaño del modelo y limitaciones. Si falta algo, anótalo.
  4. Mapea las etiquetas. Si las del modelo no son las tuyas, escribe cómo las convertirías y qué casos quedarían sin respuesta.
  5. Pruébalo con 5 casos tuyos, incluyendo uno difícil, y anota antes qué esperas.

Glosario y lista final

Palabras

dtype: tipo de dato de una columna (entero, texto, fecha).

Función: bloque de código que recibe datos y devuelve un resultado.

Token: trozo de texto (palabra o parte de palabra) que el modelo convierte en número.

Modelo preentrenado: modelo ya entrenado por otros con muchos datos.

Inferencia: usar un modelo ya entrenado para dar una respuesta, sin cambiar sus parámetros.

Zero-shot: clasificar con etiquetas que el modelo no vio al entrenarse.

Línea base (referencia): un método simple contra el que se compara.

Matriz de confusión: tabla de clase real contra clase predicha.

Precisión y recall: acierto cuando el modelo responde y cobertura de los casos reales.

Kappa: acuerdo entre dos personas descontando el azar.

Fuga de datos: que lo que se evalúa se haya visto, casi igual, al entrenar.

Generativo: modelo que produce texto token a token.
