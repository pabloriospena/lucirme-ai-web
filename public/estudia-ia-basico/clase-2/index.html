Cuatro partes que se pueden repetir

Con prompt o con código, el orden es el mismo.

1EntradaEl dato con el que arranca: un texto, una fila, una tabla.
2InstrucciónEl prompt o la función que lo transforma.
3PruebaCasos conocidos con el resultado que esperas.
4ResultadoLa salida, guardada aparte de los datos originales.

Cómo se ve cada parte en tu ruta

IA generativa

El prompt lleva contexto, rol, acción, formato y términos, como en la clase 1.
Un chat nuevo con el mismo prompt muestra si el resultado dependía de una conversación vieja.

Machine learning

Variables, una condición y una función dentro del notebook.
Una celda que usa un valor viejo da otro resultado. Por eso se reinicia y se ejecuta todo en orden.

Antes de cada resultado, una predicción: ¿qué espero que salga?

Práctica guiada · 20 min

IA generativaSin programar

  1. Abre tu documento y pega tu prompt: contexto, rol, acción, formato y términos.
  2. Cambia una entrada. Escribe qué respuesta esperas y luego envíala.
  3. Prueba una entrada vacía o fuera de tema: ¿la IA inventa o dice que no sabe?
  4. Abre un chat nuevo con el mismo prompt: ¿el resultado cambia?
  5. Guarda la versión del prompt con una nota de lo que cambiaste.
20:00
Práctica guiada · 20 min

Machine learningCon Python

  1. Abre el notebook preparado y ejecuta las celdas en orden.
  2. Cambia una entrada. Predice el resultado y luego ejecuta.
  3. Prueba una entrada inválida: ¿en qué celda se detecta?
  4. Reinicia y ejecuta todo: ¿algo cambió?
  5. Guarda una versión con un mensaje que diga qué cambiaste. Git y GitHub ayudan, sin obligarte a publicar.

Una persona de cada ruta cuenta qué pasó

Casos de aceptación · Ejemplo (escenario ficticio)

Dos casos normales y uno límite

Normal 1

«Me cobraron dos veces el agua.»
Esperado: cobros.

Normal 2

«Hay un hueco grande en la calle.»
Esperado: infraestructura.

Límite

Un mensaje vacío o con dos temas a la vez.
Esperado: pasa a revisión humana.

Con estos tres casos sabrás si tu archivo funciona o si cambió algo sin que te dieras cuenta.

Si te bloqueas

Tres salidas, sin salirte de tu proyecto

No tengo datos

Usa una muestra sintética y escribe en el brief que es inventada y qué no puedes afirmar con ella.

Copié algo que no entiendo

Explica una parte con tus palabras y cambia una condición pequeña. Si cambia lo que esperabas, ya lo entiendes.

Depende de un pago

Busca una alternativa gratuita o una respuesta preparada, y márcala como tal.
